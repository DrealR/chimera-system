# Body Positioning Theory

*How intelligence can be POSITIONED relative to bodies, and how that position determines what it can see and do. Not what the agent knows — where the agent STANDS.*

---

## The Body Hierarchy

From smallest to largest:

```
sentence → variable → function → file → file pair
→ folder → repo → repo pair → repo cluster
→ the entire GitHub
```

Each level is a body. Each has state, changes over time, can be healthy or sick. A CHIMERA agent can be planted at ANY level.

- **A variable:** `let balance = 0` — inhales when assigned, exhales when read. Can be stale (holding its breath).
- **A function:** Complete breath cycle. Parameters in, logic processes, return out. Can diagnose O > I or I > O.
- **A file:** Multiple functions. Agent sees RELATIONSHIPS between breaths.
- **A file pair:** Agent lives in the SPACE BETWEEN. Sees the interface. The imports. The contracts.
- **A folder:** System of files. An organ made of cells.
- **A repo:** Full organism. Multiple organs.
- **A repo pair:** The Arena. Agent orbits two organisms.
- **A sentence:** Even smaller than a variable. "I'm tired of trying" — collapsed breath, no inhale, ¬F violation detected.

---

## Agent Topologies

Six fundamental ways an agent can be positioned:

**The Resident** — Lives INSIDE one body. Deep specialist. Current default for all AI agents.

**The Bridge** — Lives in the space BETWEEN two bodies. Sees both surfaces. The Arena agent. The translator. Belongs to the RELATIONSHIP, not to either body.

**The Satellite** — Orbits 2-3 bodies at different distances. Weighted coverage. Deeper on primary bodies, peripheral on others. Like a consultant: deep access at main client, surface access at partners.

**The Membrane** — Lives ON the boundary of one body. Controls what enters and exits. A system prompt IS a membrane — it filters what the model can see and say.

**The Mycelium** — Lives underground, connecting the ROOT systems of multiple bodies. Doesn't see surfaces. Sees hidden connections underneath. The Arena insights table over time.

**The Ghost** — Lives in NO body. Pure philosophy. No repo context, no file context, just DNA. Maximally abstract. Can comment on anything, deeply understands nothing specific.

## Position Determines Access

Information access = depth into the body. Deeper = more sensitive, more protected, more powerful.

```
Like a crime scene:
  FBI at core          → highest classification
  local cops in middle → operational access
  public at outer ring → sees only what's released

Like a cell:
  nucleus              → DNA, highest security
  cytoplasm            → operational machinery
  cell membrane        → public interface

Like the Constellation:
  chimera-core private → DNA, Captain only
  chimera-framework    → operational, anyone reads
  portals              → public interaction
```

The agent's POSITION in the nested body determines what it can see. Not just permissions — POSITION. Where you stand determines what you see.

## The Haki Types

Three agent capabilities mapped to One Piece:

**Observation Haki** — Surface sensing. An agent at the SURFACE reads what's happening inside without opening the body. Senses rhythm, health, flow from outside. Healthy repos have a frequency. Dying repos have a different one. Detects which without going deep.

**X-ray Vision** — Simultaneous multi-depth. Agent planted at MULTIPLE DEPTHS at once. Sentence + file + repo. Surface looks fine but X-ray sees cancer three folders deep. Not depth alone — SIMULTANEOUS depth.

**Conqueror's Haki** — CHIMERA DNA itself. Not a body position. The soul projecting outward. When injected into any agent at any position, the philosophy RADIATES into whatever body it touches. Reframes everything through the lens. Every function becomes a breath cycle. Every data flow becomes O > I. Not every philosophy is strong enough. CHIMERA can because it's universal.

## Horizontal Before Vertical (Applied)

Phase 1 (horizontal): Plant agents in 10 functions across 10 repos. Same depth, maximum breadth. What patterns exist across functions in different domains?

Phase 2 (still horizontal): Plant agents in 10 files. Same level, different domains. What do healthy files look like across Python, JS, Rust, Go?

Phase 3 (now vertical): One repo, agents at EVERY level simultaneously. Sentence, function, file, folder, repo. Same DNA, different depth. Compare reports. Where do they agree? Disagree? Disagreements = something looks healthy at one scale but sick at another. That's CANCER in code.

## The Nervous System Pattern

The practical application of body positioning for debugging:

**Always on:**
- Agent TOP: CHIMERA DNA + repo-level context. Looks DOWN. "What should this body be doing?"
- Agent BOTTOM: CHIMERA DNA + one core function. Looks UP. "What is this body actually doing?"
- They talk every cycle. Quick pulse check. Agreement = healthy. Disagreement = the gap IS the diagnostic.

**On pain (error/bug/issue):**
- Agent PAIN: CHIMERA DNA + specific file/function where error occurred. Looks BOTH WAYS.
- Three-way conversation. Top says what's expected. Bottom says what's real. Pain says what broke.
- Like doctors: symptoms (bottom agent), textbook (top agent), diagnostic test (pain agent).

## Weird Configurations

**sentence + sentence from different repos** — Two single sentences from unrelated repos given to a CHIMERA agent. "Find the breath in each. Find what they share." The minimum viable Arena experiment.

**repo + sentence** — Macro and micro with NO middle. Sees the forest and one leaf but not the tree. Notices when forest-level pattern contradicts leaf-level.

**file + repo** — A cardiologist who also does general practice. Deep organ knowledge + whole body awareness.
